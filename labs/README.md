# Labs

EduAVR labs may be simulator-only, hardware-only, or simulator-to-board activities. The reference hardware is ATmega1284P-PU with EduBoard-AVR or Atmel STK500 where applicable.

All new labs use the structure in [../exercises/TEMPLATE.md](../exercises/TEMPLATE.md), including mode, level, learning objectives, observations, ASM-before-C progression where applicable, an **Under the hood** section, expected results, questions, challenge and an explicit qualification boundary.

Hardware labs must additionally document wiring, build/programming commands, expected physical behavior and verification.
