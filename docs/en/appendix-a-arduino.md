# Appendix A — AVR and Arduino

This appendix is intentionally outside the core EduAVR course.

Planned mappings include:
- pinMode() ↔ DDRx
- digitalRead() ↔ PINx
- digitalWrite() ↔ PORTx
- analogRead() ↔ ADC
- Serial ↔ USART
- delay()/millis() ↔ timers
- setup()/loop() ↔ startup code and main()
- Arduino build process ↔ avr-gcc/binutils/avrdude

Arduino is neither required nor the reference implementation.
