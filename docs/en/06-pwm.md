# PWM — hardware-generated waveforms

Pulse-width modulation (PWM) lets a timer peripheral generate a repeating digital waveform while the CPU performs other work.

## Duty cycle

For a simple PWM waveform:

```text
duty cycle = high time / period
```

A 25% duty cycle is high for one quarter of each period; 75% is high for three quarters.

## Why use the timer?

A software loop can toggle a pin, but its timing consumes CPU time and changes when other code runs. Hardware PWM is generated by the timer/output-compare hardware after configuration.

The CPU normally configures:

- waveform generation mode;
- timer clock/prescaler;
- compare output mode;
- compare value;
- output pin direction.

## ASM ↔ C

Configure the same PWM mode first through explicit AVR register operations in assembly, then in C. Disassemble the C version and identify the writes corresponding to each datasheet step.

## Changing duty cycle

Once configured, firmware can alter the compare value to change duty cycle. This becomes the basis for later labs such as LED brightness and simple waveform generation.

## Qualification

Q1 can verify register configuration, instruction flow and modeled timer/output-compare behavior.

Q2 is required for claims about the voltage waveform, frequency accuracy, rise/fall behavior, LED brightness or measurements made with real instruments.
