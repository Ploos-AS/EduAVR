# Course visual assets

Shared EduAVR visual assets belong here.

See [../VISUAL_POLICY.md](../VISUAL_POLICY.md) before adding figures.

Prefer subdirectories such as:

- `eduboard/` — photographs and canonical KiCad exports/renders;
- `screenshots/` — real toolchain, simulator and debugger captures;
- `captures/` — logic-analyzer/oscilloscope and other measured Q2 evidence;
- `diagrams/` — source-backed or conceptual teaching diagrams.

English and Norwegian should normally reuse the same language-neutral technical artifact and provide localized captions/explanation in their respective Markdown documents.

Do not place generated depictions of EduBoard, fake tool screenshots or synthetic measurement traces here as if they were real artifacts.
