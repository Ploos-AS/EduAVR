# EduAVR

Learn AVR microcontrollers from the registers up, using **assembly and C**.

EduAVR is an educational AVR environment built around open tooling, reproducible builds, simulation, debugging, and real hardware. The course is maintained as Markdown in this repository and this site is generated automatically from the same source files.

## Start the course

- [English course](en/COURSE_OUTLINE.md)
- [Norsk kurs](no/COURSE_OUTLINE.md)

## What you will learn

The course covers the AVR architecture, GPIO, stack and function calls, timers, interrupts, PWM, USART, SPI, TWI/I²C, debugging, disassembly, compiler output, programming interfaces, electronics, and protocol analysis.

## Project philosophy

EduAVR favors understanding the hardware rather than hiding it behind large frameworks. Examples therefore focus on AVR assembly and C, with simulation used wherever practical and physical hardware used when it adds educational value.
