# Appendiks B — Debugging

!!! abstract "Mål"
    Bruk avr-gdb og simulatoren til å undersøke programflyt, registre, minne og stack.

Arbeid med breakpoints, `step`, `stepi`, `info registers` og minneinspeksjon. Skill alltid mellom det debuggeren viser om firmwaretilstand og det som krever fysisk måling.

## Oppgave

Stopp et eksempel før og etter et funksjonskall og dokumenter endringer i program counter, stack pointer og relevante registre.
