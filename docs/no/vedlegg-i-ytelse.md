# Vedlegg I — Ytelse og optimalisering

## Formål
Mål før du optimaliserer, og koble ytelsespåstander til AVR-instruksjoner og ressurser.

Mål cycles/tid, interrupt-latency og ISR-varighet, Flash, statisk SRAM, stack og peripheral-throughput. Energi/effekt kalles fysisk målt bare når det faktisk er målt.

Sammenlign C og assembler på ekvivalent oppførsel med dokumentert compiler/options. Håndskrevet assembler brukes når det lærer oss noe eller løser et målt krav, ikke fordi det automatisk antas raskere.

Bygg én øvelse med flere optimization levels og sammenlign størrelse, disassembly og timing. Oppgi alltid om et tall er beregnet, simulert eller fysisk målt.
