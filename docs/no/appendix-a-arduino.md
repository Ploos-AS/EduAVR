# Appendiks A — Arduino i EduAVR

!!! abstract "Mål"
    Forstå forholdet mellom Arduino-abstraksjoner og den underliggende AVR-maskinvaren.

Arduino kan være nyttig som sammenligningsgrunnlag, men EduAVR bruker primært Assembly og C nær maskinvaren. Undersøk for eksempel hva en enkel GPIO-operasjon gjør sammenlignet med direkte registertilgang.

## Oppgave

Bygg en liten Arduino-lignende GPIO-operasjon og sammenlign maskinkoden med EduAVRs direkte C- og Assembly-varianter. Diskuter kostnaden og fordelen ved abstraksjonen.
