# Appendiks D — C, Assembly og compileren

!!! abstract "Mål"
    Forstå hvordan C-konstruksjoner uttrykkes som AVR-maskinkode og hvordan optimalisering påvirker resultatet.

EduAVR bruker C og Assembly side om side. Assembly viser maskinen eksplisitt; C lar compileren velge registerbruk og instruksjoner innenfor språkets og ABI-ens regler.

## Oppgave

Implementer samme lille algoritme i C og Assembly. Sammenlign størrelse, kontrollflyt og registerbruk i de ferdige binærfilene.
