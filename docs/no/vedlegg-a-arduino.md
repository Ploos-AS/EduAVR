# Vedlegg A — AVR og Arduino

Dette vedlegget ligger med hensikt utenfor hovedkurset i EduAVR.

Planlagte koblinger:
- pinMode() ↔ DDRx
- digitalRead() ↔ PINx
- digitalWrite() ↔ PORTx
- analogRead() ↔ ADC
- Serial ↔ USART
- delay()/millis() ↔ timere
- setup()/loop() ↔ oppstartskode og main()
- Arduino-bygging ↔ avr-gcc/binutils/avrdude

Arduino er verken påkrevd eller referanseimplementasjonen.
