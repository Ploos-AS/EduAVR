# Appendiks F — Programmering og bootloadere

!!! abstract "Mål"
    Forstå forskjellen mellom bygging, ISP-programmering og bootloader-basert oppdatering.

EduAVR holder bygging separat fra programmering slik at samme firmware kan kvalifiseres reproduserbart uten å være bundet til én fysisk programmerer.

## Oppgave

Undersøk AVRDUDE-kommandoen for STK500-oppsettet og identifiser hvilke parametere som beskriver programmerer, MCU og firmwarefil. Ikke endre fuse-bits uten å forstå konsekvensene.
