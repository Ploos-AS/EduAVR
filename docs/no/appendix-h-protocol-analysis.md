# Appendiks H — Protokollanalyse

!!! abstract "Mål"
    Lær å analysere seriell kommunikasjon som USART, SPI og TWI/I²C systematisk.

Start med protokollens rammer, timing og tilstandsmaskin. Sammenlign deretter firmwaretilstanden med det som faktisk observeres på ledningen når fysisk maskinvare brukes.

## Oppgave

Velg USART, SPI eller TWI/I²C. Beskriv hva simulatoren kan verifisere, og lag en separat plan for Q2-måling med egnet instrument eller logic analyzer.
