# Contributing to EduAVR

EduAVR is a bilingual educational project.

English and Norwegian lessons should keep matching lesson numbers and learning objectives. Translations need not be word-for-word, but technical meaning and exercises should remain aligned.

Core examples target ATmega1284P unless another MCU is explicitly documented. Prefer direct register-level AVR code. Do not introduce Arduino framework dependencies into the core course.

Required course tooling must be free of charge and the normative toolchain should be open source. Proprietary tools may only be documented as optional alternatives.
