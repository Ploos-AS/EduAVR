# Licensing

EduAVR uses the Ploos-AS mixed-project licensing model:

- Software, tooling and code examples: MIT
- Course text and documentation: CC BY-SA 4.0
- Future hardware, PCB and HDL/gateware: CERN-OHL-P-2.0

The full MIT text is at the repository root. Full applicable documentation/hardware license texts must be added before those deliverables are published.
